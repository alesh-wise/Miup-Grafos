# MIUP - Algoritmos de Grafos 🚀

Este repositório reúne uma coleção de exercícios resolvidos sobre algoritmos de grafos, desenvolvidos como preparação para a **MIUP (Maratona Inter-Universitária de Programação)**.

O foco principal é a implementação eficiente em **C++** de algoritmos clássicos aplicados a problemas de programação competitiva, incluindo:
* Busca em Largura (BFS) e Busca em Profundidade (DFS)
* Contagem de Componentes Conexas
* Cálculo de caminhos mais curtos e reconstrução de trajetos
* Exploração de matrizes (Grid Graphs)
